Fluxo de atendimento

Arraste uma caixa para movê-la — mover nunca muda a estrutura. Puxe um pino (qualquer um dos lados) até outra caixa para pôr esta dentro daquela: quem se move é sempre a caixa de onde você puxou, então dá para pôr várias dentro da mesma. Clique para editar no lado. Entre irmãos, a caixa mais alta é olhada primeiro.

Regras do código

As dezesseis que a extensão sabe reconhecer. Arraste uma para o quadro, ou clique em Pôr para largá-la no meio da vista. Apagar uma caixa nunca apaga a regra — ela volta para cá.

O padrão mudou?

Compara este quadro com o padrão de hoje. Nada entra sozinho: no quadro a posição é a prioridade, então quem decide onde cada caixa vai é você.

Salvar e carregar

O quadro grava sozinho a cada mexida. Isto aqui é para guardar versões: salve com um nome, mexa à vontade, e volte quando quiser.

Mandar o fluxo para o Claude

Copia o fluxo inteiro em texto — a estrutura, as condições, os desfechos e as suas observações no ramo a que pertencem. Cole na conversa e eu mexo no que você pediu.

Testar uma conversa

Cole o que o contato escreveu — uma mensagem por linha, a última embaixo. O caminho que vencer acende no quadro.

Fora da conta: etiqueta que dispensa, modelo mapeado, pedido feito hoje e histórico de envios — dependem do contato, não do texto.
